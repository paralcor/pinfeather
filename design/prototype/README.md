# 片羽界面原型

记录日期：2026-10-22

`prototype.html` 是片羽桌面端的界面原型：单文件，无依赖，离线用浏览器直接打开。它只用来确定界面结构、交互和视觉方向，**不是可运行的产品**。里面的数据全是假的，回贴、剪贴板、MCP、文件导出都在浏览器里模拟。

产品范围和技术问题以[项目交接文档](../../rumo_clipboard_handoff/docs/pinfeather_project_handoff.md)为准，图标见 [`assets/icon/`](../../assets/icon/)。

## 怎么看

页面顶部的黄色控制栏**不属于产品**，用来切换原型状态：

| 控件 | 作用 |
| --- | --- |
| 场景 | 快捷面板（模拟桌面、记事本、任务栏、托盘）／管理窗口（模拟 Windows 窗口） |
| 主题、强调色、密度 | 浅色／深色；晨曦粉／中性；Nova 紧凑／标准 |
| 面板布局 | 快捷面板单列，或列表 + 右侧预览 |
| 回贴结果 | 成功；或“目标窗口已变化”，演示不自动粘贴时的处理 |
| 历史列表 | 行／卡片 |
| 模拟一次复制 | 产生一条新剪贴内容；暂停收录或来源在排除列表里时不保存 |

当前状态会写进地址栏参数（如 `?scene=manager&page=collections&theme=dark`），可以直接分享某个状态。

## 实现约定

优先复用成熟库，组件源代码可控，设计语言统一，严格限制重复依赖。每类能力只用下面这一个库，不再引入功能重叠的库：

| 用途 | 库 |
| --- | --- |
| UI 组件与风格 | shadcn/ui，风格 Nova（依赖 Tailwind CSS；组件源码复制进项目，可直接修改） |
| 图标 | Lucide（`lucide-react`） |
| 动画 | Motion（`motion/react`） |
| 可调宽度的分栏 | react-resizable-panels |
| 拖拽排序 | dnd-kit（`@dnd-kit/core`、`@dnd-kit/sortable`） |
| 状态管理 | Zustand |

桌面宿主按交接文档的候选：Tauri + React / TypeScript。各库用当前稳定版，版本由实现者确定。

## 原型元素与实现的对应

| 原型里 | 实现时用 |
| --- | --- |
| CSS 变量 `--background`、`--foreground`、`--muted`、`--border`、`--primary`、`--ring` 等 | shadcn 主题变量，同名，写进 `globals.css`；浅色、深色两套 |
| `.btn` / `.input` / `.switch` / `.badge` / `.chip` / `.kbd` | shadcn 的 Button、Input、Switch、Badge、Toggle / ToggleGroup、Kbd |
| `.menu`、托盘菜单、“加入集合”菜单 | DropdownMenu |
| 对话框“从历史添加”、确认框 | Dialog、AlertDialog（焦点进入、困在框内、Esc 关闭） |
| `select.input` | Select |
| 右下角提示和“撤销” | Sonner（shadcn 的 toast） |
| 快捷面板的搜索 + 列表 | Command（cmdk） |
| 分隔条 `.resizer` | react-resizable-panels 的 `PanelGroup` / `Panel` / `PanelResizeHandle`；导航栏用 `collapsible`，窄到阈值时只剩图标 |
| 集合片段拖拽、`Alt+↑/↓` 移动 | dnd-kit `SortableContext` + `useSortable`，同时启用 PointerSensor 和 KeyboardSensor |
| 面板弹出、列表项进入、落位、toast 动画 | Motion，时长 150–300ms，遵守“减少动态效果”设置 |
| `ic("名字")` 里的图标 | Lucide 同名图标，如 `search` → `Search`、`layers` → `Layers`、`gripVertical` → `GripVertical` |
| `createStore()` 的 `getState` / `setState` / `subscribe` | Zustand store，建议按下面拆分 slice |

建议的 Zustand slice：

| slice | 内容 |
| --- | --- |
| capture | 收录开关、排除应用、敏感内容、保留时长、条数上限 |
| history | 历史条目（摘要）、筛选、选中、多选 |
| quickPanel | 是否打开、搜索词、类型、选中项、预览开关 |
| collections | 集合、片段顺序与文本、模板选择、参数值、对 AI 开放 |
| templates | 模板列表与内容 |
| ai | AI 接入总开关 |
| ui | 主题、密度、分栏宽度、toast |

历史条目只在前端保存摘要和元数据，大内容和图片按需从 Rust 侧读取（交接文档候选方案 D 的 3.1 节）。

## 视觉

- 中性灰阶为主，强调色只用在主按钮、选中态和焦点：浅色 `#b8325a`，深色 `#f47a99`。它们取自图标的晨曦粉，见 [`assets/icon/README.md`](../../assets/icon/README.md)。
- 字体：界面用 Segoe UI Variable / 微软雅黑 UI，代码用 Cascadia Code / Consolas。
- 来源应用在原型里画成字母色块，实现时换成读取到的应用图标；拿不到时再退回字母色块。

## 界面与交互

### 快捷面板

全局快捷键唤出（原型默认 `Ctrl+Shift+V`，可在设置里改），或单击托盘图标。

| 按键 | 动作 |
| --- | --- |
| 输入 | 即时搜索，中文片段也要能搜到 |
| ↑ ↓ | 选择 |
| Enter／单击 | 粘贴到唤出前的窗口 |
| Shift+Enter | 按纯文本粘贴 |
| Ctrl+1–9 | 直接粘贴第 1–9 条 |
| Tab | 单列布局下展开预览 |
| Ctrl+D | 收藏／取消收藏 |
| Ctrl+Shift+S | 加入当前集合 |
| Esc | 关闭，焦点回到原窗口 |

- 收录暂停时，面板顶部显示提示条，可以直接恢复。
- 托盘图标右键菜单：打开快捷面板、打开片羽、暂停／恢复收录、设置、退出；暂停时托盘图标变淡。
- 用过的条目移到最前。

### 历史

- 三栏：导航、列表、预览。分隔条可拖动，也可聚焦后用 ←→ 调整。
- 筛选：搜索、类型、来源应用、只看收藏，按今天／昨天／更早分组。
- 多选：Ctrl / Shift 点选，出现批量栏，可加入集合或删除；Delete 键删除。
- 删除后的提示带“撤销”。
- 预览区显示：内容、来源应用和进程名、窗口标题、时间、大小、保存的格式、所在集合。

### 集合

- 片段从历史复制一份进集合单独保存，历史清理和删除都不影响集合；在集合里编辑也不改历史原文。
- 选一个指令模板后，按模板参数生成表单；没填的参数会标出，复制时原样保留成 `{{参数}}`。
- 右栏是合并结果（Markdown）：复制全部、导出 `.md`。
- “对 AI 工具开放”按集合单独开关，只读；AI 接入总开关关闭时不可开。

### 指令模板

- `{{参数名}}` 是参数，同名参数只填一次。
- `{{材料}}` 放集合里的片段；模板里没写时，片段附在最后。
- `\{{` 输出字面的 `{{`。
- 编辑区下方实时显示识别到的参数和渲染效果；右侧可以试填。

### 设置

- 通用：唤出快捷键录制（必须带修饰键；`Win+V` 提示与系统剪贴板历史冲突）、开机启动。
- 收录：总开关；遵守“不进入剪贴板历史”的标记；排除应用；保留时长（收藏和集合不清理）；条数上限（100–100000，输错有提示）。
- AI 接入：总开关、已开放集合列表与“撤销开放”、风险提示、接入命令示例（命令名是暂定的）。
- 设备：局域网互通，标为后续版本，控件禁用。
- 关于。

## 模拟行为与真实实现

| 原型里 | 真实实现要做的 | 交接文档 |
| --- | --- | --- |
| 回贴：把文字插进模拟的记事本 | 记录并校验目标窗口，注入前复核前台窗口、检查注入结果；失败时不报成功，内容留在剪贴板让用户手动粘贴（原型的“目标窗口已变化”演示了这个界面） | R1 |
| 收录：点“模拟一次复制” | 监听剪贴板变化，识别片羽自己的写入，处理读取失败与重试 | R2 |
| “保存的格式”只是展示 | 一条记录对应多份格式载荷，原子写入、恢复和清理 | R3 |
| “对 AI 工具开放”只是开关 | 按集合检查访问范围、撤销后立即生效、只读、限制数量和大小；工具注解不能代替权限控制 | R4、R5 |
| 搜索是简单的子串匹配 | 定义中文一两个字、长片段、英文、代码、链接的检索行为，再选索引方案 | R6 |
| 来源应用就是数据里的字段 | 前台窗口不一定是写入剪贴板的程序，界面已注明 | 方案 D 3.2 |
| 导出 `.md` 用浏览器下载 | 系统保存对话框 | — |

## 原型里定下、但还需要确认的细节

- 快捷面板单击即粘贴，鼠标悬停跟随选中。
- 快选用 `Ctrl+1–9`，不用单独的数字键，避免和搜索输入冲突。
- `Ctrl+Shift+S` 加入的是集合页当前选中的集合。
- 集合片段是复制出来的独立副本，编辑不回写历史。
- 收藏的条目不受保留时长清理。

## 原型来源

原型的截图和自检脚本由维护者另行存档，不在仓库里。自检脚本会截取各场景截图，并自动检查主要交互：唤出、搜索、回贴、回贴失败、托盘菜单、暂停、多选、删除撤销、拖拽排序、参数提示、模板试填、快捷键录制、条数校验和窗口宽度。修改原型后，同步更新这里的 `prototype.html`。
