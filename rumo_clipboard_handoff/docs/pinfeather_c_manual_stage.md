# 快捷面板手动复用

快捷面板支持搜索已保存的文字历史、选择条目查看正文、明确复制，再由用户切回目标应用粘贴。搜索框保持可编辑，不要求先点击“完成输入”。结果旁显示当前查询；继续输入会更新结果，并清除旧选择和未执行的复制资格。

## 使用

应用以显式 `--data-dir <独立目录的绝对路径>` 启动，默认暂停，不回落到个人数据目录。需要开始收录时由用户主动开启；数据路径、保留和删除策略尚未作为个人日用默认值交付。

1. 从主窗口或 Ctrl+Alt+V 打开快捷面板，输入搜索词。
2. 点击条目的“查看正文”，或点击“浏览结果”。输入法选词时的点击可以同时打开预览；选择和预览本身不复制。
3. 确认目标正文后，再单独点击一次“复制纯文本”。在结果列表中也可用新的 Enter 按下并释放来明确复制。复制后自行切回目标应用粘贴。

搜索中出现的候选按键、此前未释放的键、重复事件或同次默认点击不能沿用为复制动作。修改查询、返回搜索或打开新会话会使旧选择和待执行动作失效。已交给宿主的复制仍由原操作完成，不会因继续搜索而补发。

“返回搜索”保留查询并清除正文选择；“清空搜索”恢复最近历史。没有匹配结果时不保留旧正文或复制资格。列表默认每页50条，“加载更多”取得下一页。

快捷面板失去焦点会隐藏，切回聊天或其他应用后需重新打开。主窗口关闭可能只隐藏到托盘；结束程序应使用“退出片羽”，并确认退出完成。未保存队列和保存失败继续可见，不能用关闭窗口代替保存/退出成功。

## 复制反馈

- “已复制，可手动粘贴。”表示对应明确操作已返回成功。
- 未执行复制时可以在确认原因后手动重试；程序不自动重试。
- 无法确认结果时，剪贴板可能已变化，由用户检查，不自动恢复旧内容或重放请求。

复制按所选存储ID读取完整文本，不以当前已加载的预览片段代替全文。预览可继续分段读取；读取错误、查询变化和迟到回复不得让旧内容冒充当前选择。
