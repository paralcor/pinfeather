# 个人文字历史

`tools/start-personal.ps1 -Executable <片羽exe完整路径>` 手动启动，数据目录固定为 `D:\Develop\PinfeatherData\personal`，默认强制暂停启动。想在下次启动时沿用上次手动选择，可在主窗口开启「启动时恢复上次手动收录状态」，并在运行脚本时加 `-ResumeCapture`。偏好保存在当前目录的 `startup-capture.json`。退出排空保留原选择，关闭偏好会清除该选择。其他目录的历史需要单独恢复。

使用 Ctrl+Alt+V 或主窗口按钮打开快捷面板，搜索、查看正文，再单独点击“复制纯文本”，自行切回应用粘贴。主窗口关闭可能隐藏到托盘；结束运行请点“退出片羽”。

## 容量与删除

历史上限为 10,000 条、正文载荷合计 256 MiB。这不是数据库文件或 WebView 目录的磁盘大小上限。达到容量边界时拒绝新增，不自动淘汰旧条目；未保存内容与错误会显示在主窗口。

管理前暂停收录，等待未保存队列为零。在主窗口「历史管理」中可删除选中的条目，已收藏条目需先取消收藏才能删除。「清空未收藏历史」删除整个历史库中的未收藏条目，保留已收藏条目，且不受当前搜索词限制。两种删除操作均需再次确认，无法撤销。已有备份不受影响。删除是逻辑删除，不承诺从磁盘、备份或文件系统中安全擦除字节。

## 备份与恢复

主窗口“备份历史”将已保存历史、正文、格式载荷及元数据保存到当前数据目录下 `backups/history-<唯一编号>.sqlite3`。备份不含未保存队列、排除设置或 WebView 数据。成功后显示实际路径；请另外保存到需要的备份介质。备份出错或结果未确认时先核对，不把部分文件当作成功备份。

退出片羽后，使用独立工具：

```powershell
& '<history_restore.exe完整路径>' '<备份sqlite3完整路径>' '<尚不存在的新目录完整路径>'
```

工具独立运行，接受 schema 1 和 schema 2 备份，验证库标识、完整性和容量，并拒绝未知版本。它只向新目录写入 `history.sqlite3`，源备份保持不变。恢复 schema 1 备份时，只将新目录中的目标库升级到 schema 2。失败可能留下只写入了一部分的目标目录。重试时请选择另一个尚不存在的目录。

恢复目录只有历史，不会继承排除设置。先核对并重新设置排除项，再决定开启收录。需要浏览恢复内容时，显式使用片羽 `--data-dir '<恢复目录>' --start-paused`；个人启动脚本仍指向固定个人目录，不会自动切换。
