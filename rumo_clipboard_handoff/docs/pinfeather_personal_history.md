# 个人文字历史

`tools/start-personal.ps1 -Executable <片羽exe完整路径>` 手动启动，数据目录固定为 `D:\Develop\PinfeatherData\personal`。每次启动默认暂停，点击“开始收录”后才监听新内容；不会导入其他目录的历史。

使用 Ctrl+Alt+V 或主窗口按钮打开快捷面板，搜索、查看正文，再单独点击“复制纯文本”，自行切回应用粘贴。主窗口关闭可能隐藏到托盘；结束运行请点“退出片羽”。

## 容量与删除

历史上限为 10,000 条、正文载荷合计 256 MiB。这不是数据库文件或 WebView 目录的磁盘大小上限。达到容量边界时拒绝新增，不自动淘汰旧条目；未保存内容与错误会显示在主窗口。

管理前暂停收录，等待未保存队列为零。选择历史后，在主窗口“历史管理”中按条删除；“清空全部历史”作用于整个历史库，不受当前搜索词限制。两者均需再次确认，不能撤销。已有备份不受影响。删除是逻辑删除，不承诺从磁盘、备份或文件系统中安全擦除字节。

## 备份与恢复

主窗口“备份历史”将已保存历史、正文、格式载荷及元数据保存到当前数据目录下 `backups/history-<唯一编号>.sqlite3`。备份不含未保存队列、排除设置或 WebView 数据。成功后显示实际路径；请另外保存到需要的备份介质。备份出错或结果未确认时先核对，不把部分文件当作成功备份。

退出片羽后，使用独立工具：

```powershell
& '<history_restore.exe完整路径>' '<备份sqlite3完整路径>' '<尚不存在的新目录完整路径>'
```

工具不启动片羽。它验证库标识、schema 1、完整性和容量，然后只向新目录写入 `history.sqlite3`，不覆盖已有目录、不自动迁移未知版本。失败可能留下新建的部分目标目录；保留它并改用另一个新目录，不直接重试覆盖。源备份保持不变。

恢复目录只有历史，不会继承排除设置。先核对并重新设置排除项，再决定开启收录。需要浏览恢复内容时，显式使用片羽 `--data-dir '<恢复目录>' --start-paused`；个人启动脚本仍指向固定个人目录，不会自动切换。
