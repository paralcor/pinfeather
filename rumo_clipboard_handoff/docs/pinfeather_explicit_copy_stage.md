未确认时搜索和结果更新继续，但浏览、条目选择、正文读取、复制和标题区“隐藏快捷面板”均不能由点击或键盘触发。观察到 compositionend 本身不授权任何动作。“完成输入”的完整指针或键盘操作只冻结查询、移走编辑焦点并显示提示，不选中、不读取正文、不复制、不隐藏。只有当前输入轮次已明确确认并观察到结束，才可用后续独立操作浏览。新输入法活动撤销确认，返回可编辑状态并清空旧选择；旧确认指针或键盘释放不能确认新轮次。

确认时尚未观察到结束，则保持等待，并提供“修改搜索”恢复编辑；没有超时放行或迟到动作回放。“修改搜索”和“返回搜索”保留查询、清空选择与预览并聚焦输入框；使用输入法后的编辑需要重新确认。完成、修改、浏览及返回使用独立按钮元素；完成按钮的 Enter/Space 在匹配释放时只完成一次，repeat、持有按键和默认 click 不能激活下一动作。既有候选按键释放保护继续适用。浏览后的列表方向键、明确复制完整存储正文、copied / not_written / unknown 反馈及分页沿用原契约。

同一组合输入轮次内的 compositionupdate 保留正在进行的完成操作和等待中的确认；新的 compositionstart，或 Process/229/isComposing 按键活动仍撤销旧确认。等待结束时保留当前轮次的查询更新，并在结束时按本轮起始替换范围与最终组合文本写入完整查询；最终 change 晚于结束也不会丢掉提交文本。就绪后的普通编辑仍需先“修改搜索”，旧轮次或旧会话事件不能修改当前查询。最终查询结果尚未返回时不能浏览，旧查询结果不替代最终结果。

复制后面板保持打开并显示原 copied / not_written / unknown 三态。Esc、面板 X 和失焦隐藏面板；不主动恢复外部焦点。主窗口 X 仍全局退出，驻留与托盘属于后续 M2。面板自己的中文输入通过 composition、Process/229 与相关物理按键释放边界保护候选 Enter/Esc/箭头，不以固定延时证明输入已提交。仅当最后观察到的 Enter/Esc 按下并匹配释放、其后没有新候选活动时，组合结束后的下一次独立 Esc/Enter 才可操作；旧方向键或 Space 释放不能证明后续提交/取消键已释放。无法区分候选导航与提交时保守拦截，仍可用组合结束后开始的新指针手势选择、复制或隐藏；组合期间开始、导致组合结束的同一次手势不触发面板动作。候选默认 click 继续受保护；已观察终结键释放并结束组合后，Tab 不授权 click，随后独立 Space 通过按钮原生默认 click 激活一次。真实 WebView/输入法顺序和可用性仍需后续人工核对。

宿主会话由 `PanelSessions` 的锁拥有；受信本地 quick-panel 的当前 ready 会话，才能在同一锁内原子接纳到既有 `HostRuntime.queue_copy`。等待写入结果在锁外，主窗口与面板共享原全局 WritePermit、存储线程和 WindowsWriter。隐藏先撤销新动作；已接纳操作仍可能完成，不声称隐藏取消系统写入，超时也不提前释放 permit，迟到结果仅归原会话。通用 `copy_clip_text` 限 main；面板使用严格会话封装的 `copy_manual_panel_text`。前端和 fixture 同包替换，无数据库或持久配置迁移。

面板状态/动作命令为 `get_manual_panel_state`、`open_manual_panel`、`ready_manual_panel`、`hide_manual_panel`；身份只取 Tauri 注入的窗口和本地 URL。会话字段与复制封装由 [Rust 契约](../../src-tauri/src/contracts.rs) 定义，[共享夹具](../../tests/fixtures/contracts/manual_panel.json) 与 TypeScript 同步验证。面板权限只新增本地事件订阅/解除订阅，不开放外部导航。热键由单一线程注册、派发和注销，主退出先停止面板新动作并回收热键，再走原 shutdown；注销/回收失败保留线程归属和主窗口以便重试。

## 行为与边界

- 在现有正文预览区域提供原生按钮“复制纯文本”，用户可用鼠标或键盘明确触发。查看、选中、搜索、刷新或加载预览本身均不写入剪贴板。
- 复制点击时所选条目的完整 `CF_UNICODETEXT`，不复制列表摘要或当前已加载的预览分片。沿用已有文本载荷上限；不增加 HTML、图片转换或任意正文写入。
- 前端只提交请求标识和条目 ID。宿主验证调用窗口、来源、请求字段、ID、存储记录和文本载荷，按 ID 读取已提交内容；前端不能提供待写文本、任意路径或窗口标签作为授权依据。
- 复制不依赖开启收录。宿主不可用、正在退出、无有效选择或无文本载荷时不启动写入；不支持复制的 bridge 明确显示不可用，不回退到浏览器剪贴板 API。
- 点击后仅允许一个未结束的复制操作。更换选择、查询或组件生命周期不能重发，也不能把旧条目的完成提示显示成新条目复制成功。宿主另行限制未结束操作，不能只依赖按钮禁用。
- 保留现有来源登记、内部标记、历史/云禁用标记和句柄转移规则，避免内部复制再次收录。不得按文本相等或固定时间屏蔽外部复制。
- 收录暂停且来源登记表满时，仅回收已完成、非最近一次确认写入的登记；进行中的操作和最近一次确认写入的来源继续保留。此保护只由写入完成且取得有效 sequence 时推进；内部或外部旧快照的分类不能改变它，写入前失败也不能清除它。暂停已清空旧采集队列并更新 epoch，跨 epoch 的迟到结果在来源分类前被拒绝；同一 epoch 内晚完成的旧快照仍可分类，但不能使写入来源保护回退。
- 不激活其他应用，不检查目标或 IME，不注入按键，不自动粘贴，不自动重试，不恢复旧剪贴板。复制不改变历史排序。

## 接口和结果

新增受现有本地调用授权约束的 `copy_clip_text` 命令；请求为 `{ request_id, clip_id }`，ID 和请求标识沿用已有共享契约限制，拒绝多余字段。结果必须关联同一请求和条目。Rust 契约为权威，TypeScript 校验、bridge、模型、UI 和共享夹具同步更新。

结果固定为 `{ request_id, clip_id, outcome, reason }`，拒绝多余字段并复核两个 ID；`outcome` 使用以下三态，`copied` 的 `reason` 必须为 null，其他结果必须提供已有共享 `ErrorCode`。命令授权或请求解析失败仍沿用原错误格式；前端对发出请求后的 IPC 拒绝保守显示 unknown。

| 结果 | 判定依据 | 用户反馈 |
| --- | --- | --- |
| `copied` | 文本、必要来源/隐私标记以及关闭操作均成功 | 已复制，可手动粘贴；不声称目标已接收 |
| `not_written` | 宿主明确在可能改变剪贴板之前拒绝，如无记录、无文本、队列满或排队到期 | 未执行复制及可理解的原因；不把所有底层错误都归到此状态 |
| `unknown` | 已可能改变剪贴板但完整结果未获确认，或发送后的响应超时、断连、不可验证 | 无法确认复制结果，剪贴板可能已变化；不自动重试 |

保留有界等待和已有 3 秒内部请求预算。到期且尚未开始的任务不得随后启动写入；已进入系统调用的操作不能假称已取消。调用者超时不释放仍执行中的写入所有权，不允许新复制越过旧操作。进入可能改变剪贴板的边界前检查退出和截止时间；开始后的迟到完成不能触发新的写入或对当前选择显示成功。

写入还须持有监听窗口的有效借用。宿主退出或采集失败清理先撤销新借用，等待既有写入完成关闭、writer 析构及来源登记结束后，才关闭监听资源；等待期间监听消息线程继续泵送。宿主的有界退出等待到期仍返回清理未完成并保留线程，不能提前宣告可退出。来源登记保留已完成快照的归属信息，但旧窗口数值本身不能授权新写入。意外的系统资源丢失仍可能使调用失败，这一顺序不承诺恢复已被外部销毁的窗口。

Win32 多格式写入不是可回滚事务。清空后的分配/格式设置/关闭失败均不得报成功；必须保守反映副作用不确定性。现有内部 `write_stored_text` 调用者及测试保持可用，行为不能因新增 IPC 静默改变。

接口为同一桌面包内的增量能力，前后端一起交付，不做数据库迁移。不具备复制能力的既有测试 bridge 仍可执行原有查询/预览；新增功能不可用时不能伪造成功。

## 风险和验证

风险等级为高：这是由 UI 触发的系统剪贴板副作用，涉及授权、跨进程契约和异步超时。安全不变量是“没有明确操作和合法存储条目就不写入；没有完整写入确认就不显示成功；未完成写入始终有唯一所有者”。

实现先保留失败回归，再做最小变更。正式测试覆盖：

1. 共享契约有效/无效请求、额外字段、ID 边界和结果关联；授权失败在副作用前被拒绝。
2. 实际宿主查询队列与内存存储读取完整 Unicode 文本；通过 mock writer 执行生产写入路径，不调用真实剪贴板。
3. 缺记录、无文本、占用/打开失败、清空或分配/设置/关闭失败及来源标记分类；不得出现假成功或句柄所有权丢失。
4. 排队过期、执行中超时、迟到结果、重复点击、并发复制及退出；未开始到期任务零写入，未完成任务禁止替换。
5. UI 明确点击、分页文本、切换选择/查询、卸载、宿主缺失、无文本条目、成功/失败/未知反馈及键盘可达性。
6. 既有 R1 退出和 R3 进程/线程所有权回归继续通过，类型检查、前端构建及非测试 Rust 编译通过。

普通自动检查不得启动真实 worker/listener、Pinfeather 或目标应用，不访问既有数据库，不读写系统剪贴板。需要浏览器验证时，仅使用无头 Playwright、隔离的 mock bridge，禁止调用真实剪贴板 API。新合成数据放任务归档目录或内存中。

源码、mock 故障注入、构建和真实现场证据分别记录。离线通过只能标记“实现及离线验收完成，真实剪贴板待验”，不能标记本阶段现场通过或首轮完成。后续现场须另行冻结确切范围并取得新的准备确认。
