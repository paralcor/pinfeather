# 片羽 / Pinfeather 图标

定稿日期：2026-10-22。商标和图形近似检索都**尚未做**，正式注册或大规模使用前需要先核查。

`overview.png` 是全部文件的一页总览。

## 构成

一枚回形针别住一片羽毛，羽毛从针下垂挂、微微摆开。羽根上半段压在针上、下半段被针压住，像真的别住了。羽片有三道切到羽轴附近的裂口，分成几片，对应「片羽」和零碎的剪贴内容。回形针说明这是剪贴板。

片羽的视觉独立于母品牌 PARALCOR，不用星光蓝和深色底。

## 文件

| 文件 | 用在 |
| --- | --- |
| `pinfeather-app-icon.svg` | 圆角应用图标，渐变底，用于桌面、网站和文档 |
| `pinfeather-app-icon-square.svg` | 直角方块，交给系统自己加圆角时用（如 iOS） |
| `pinfeather-favicon.svg` | 网站图标，32px 及以下的简化几何 |
| `pinfeather-mark-*.svg` | 透明底图形，四个配色版本 |
| `pinfeather-tray-*.svg` | 系统托盘，透明底，简化几何 |
| `png/` | 以上文件的 PNG：应用图标 180 / 512 / 1024（另有直角 1024），favicon 16 / 32 / 48，托盘 16 / 20 / 24 / 32（对应 Windows 100%～200% 缩放），图形 256 / 1024 |
| `params.json` | 生成这套图标的全部参数 |

## 配色

| 部分 | 色值 |
| --- | --- |
| 应用图标底 | 线性渐变，左上 `#ffb79a` → 右下 `#f26a8d` |
| 应用图标上的羽毛 | `#ffffff` |
| 应用图标上的回形针 | `#b8325a` |

透明底图形和托盘图标不用渐变，配色按所在背景选：

| 后缀 | 用在 | 羽毛 | 回形针 |
| --- | --- | --- | --- |
| `-light` | 浅色背景 | `#ee5f84` | `#b8325a` |
| `-dark` | 深色背景 | `#ffffff` | `#ffb2c4` |
| `-black` | 单色印刷、浅色背景 | `#000000` | `#000000` |
| `-white` | 反白、深色或图片背景 | `#ffffff` | `#ffffff` |

## 使用规则

- **最小尺寸**：32px 及以下用 `pinfeather-favicon.svg` 或 `pinfeather-tray-*.svg` 的简化几何。简化几何去掉了羽轴细缝，减少了裂口，线条也加粗了。16px 时回形针只剩几个像素，这是定稿时接受的取舍。
- **留白**：透明底图形四周至少留出图形高度的 1/8。
- **不要**：
  - 改变羽毛的摆角，或回形针和羽毛的相对位置；
  - 给图标加阴影、描边或发光；
  - 把应用图标的渐变底用在透明底图形上；
  - 把羽毛和回形针拆开单独使用。

## 重新生成

图标原型和导出脚本由维护者另行存档，不在仓库里。原型带上 `params.json` 里的参数打开即为定稿。要改图标，请联系 [@rumoii](https://github.com/rumoii)。

Tauri 工程建好后，用 `tauri icon assets/icon/png/pinfeather-app-icon-1024.png` 生成各平台图标集（含 `.ico`）。

改参数时同步更新 `params.json`，并重新检查 `overview.png`。
